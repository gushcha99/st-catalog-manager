## Формат и различия

- UTF-8, разделитель `;`, корректное чтение через стандартный `csv` с `newline=""`. Все цены и идентификаторы сохраняются строками.
- Международный каталог имеет `Tabs:1`, `Tabs:2`, `Tabs:3`; остальные — 26 полей. Заголовки и их порядок сохраняются отдельно для каждого сайта.
- Встречаются HTML, символы кириллицы/армянского алфавита, кавычки и разделители внутри ячеек. Все значения участвуют в тестах round-trip.
- Названия свойств бывают с завершающим двоеточием: `Ближайшие группы:`. Тогда корректное по структуре исходника начало значения — `Ближайшие группы::`. Автоматической замены нет.
- Есть товары с несколькими свойствами (например, English for ACCA). Простой редактор расписания к ним не применяется.
- В исходниках некоторых учебных материалов встречается строка с `INT&amp;amp`, содержащая `;`. Безопасный однозначный разбор как одного свойства не гарантируется: показывается предупреждение, значение сохраняется дословно.

## Проверка исходников

SHA-256 каждого CSV записан в `st_catalog/data/manifest.json`. Приложение читает эти файлы только при первом заполнении пустой базы. Пользовательские изменения хранятся отдельно.

Первоначальная база `initial-catalog.sqlite3` содержит эти же 556 строк без правок. Это дополнительная резервная поставка; приложение не заменяет ею существующую базу при обновлении.
