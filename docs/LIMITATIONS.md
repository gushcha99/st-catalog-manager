# Известные ограничения

1. Windows EXE не собран и не запущен в текущей macOS-среде. Прилагаются исходники, PowerShell/PyInstaller и GitHub Actions. Нет подтверждения Windows-совместимости до фактического запуска сборки.
2. Qt 6.8.3 завершает запуск в текущей песочнице: системный запрос `hw.optional.neon` запрещён, сообщение «Incompatible processor … neon». Поэтому локальный GUI smoke-test и визуальная приёмка не выполнены. GUI-тесты написаны и включены в Windows-сборку, но не считаются прошедшими здесь.
3. Реальный импорт в Tilda не выполнялся. Не доказаны приём назначенных новых UID, обработка двойного двоеточия и всех комбинаций опций. Сначала испытайте на копии проекта.
4. Визуальное редактирование HTML ограничено текстовыми фрагментами. Нет полноценного WYSIWYG форматирования, редактирования iframe или CSS; для этого используется исходный HTML. Предпросмотр Qt может отличаться от браузера Tilda. Смена режима сама по себе не сериализует и не изменяет HTML.
5. Modifications, Tabs и неизвестные поля доступны в расширенном редакторе исходного значения. Нет визуального конструктора дополнительных опций. Проверка синтаксиса консервативна и не заменяет проверку Tilda.
6. Упрощённый редактор расписания поддерживает одно однозначно распознанное свойство. Варианты с несколькими свойствами сохраняются и проверяются по названиям родителя, но для правки используются исходные Editions. Новые такие комбинации не создаются мастером.
7. Нет автоматического исправления структуры армянского каталога или UI для переназначения Parent UID. Существующая отдельная позиция и её дочерний вариант не объединяются с основным ДипИФР. Исправление можно выполнить в Tilda и загрузить новую выгрузку.
8. «Актуальность не подтверждена» — консервативный статус, даже после новой загрузки. Прямой проверки сайта нет. Совпадение со свежим CSV проверяется по значениям отдельных полей, а не как гарантия полной синхронизации сайта.
9. Отсутствие в полной выгрузке требует явного решения, кроме ранее помеченных неизменённых удаляемых записей. Ошибочно объявленная полной частичная выгрузка может породить множество конфликтов. Не подтверждайте отсутствие без проверки.
10. Режим изменений выгружает целые затронутые семейства. Это может включить неизменённых братьев/сестёр и родителя. Исходные предупреждения остаются в отчёте; критическая ошибка блокирует весь соответствующий сайт, другие сайты можно выбрать отдельно.
11. GUI обрабатывает операции синхронно; оптимизирован для текущих 556 строк, фоновые задачи/прогресс для очень больших каталогов не реализованы.
12. Нет MSI-инсталлятора, цифровой подписи, автообновления, серверной работы и облачной синхронизации. Поддерживается переносимая папка Windows с EXE.
13. Резервные копии локальны. Для защиты от поломки диска сохраните копию отдельно. База не зашифрована.
14. При аварийном завершении ровно между публикацией файлов и фиксацией SQLite может остаться экспортная папка без истории. Проверьте содержимое и повторно сформируйте экспорт; исходные данные при этом не меняются.
15. Сохранённые файлы экспортов не входят в резервную копию SQLite, только их снимки и пути. Перенос базы не переносит старые CSV-папки, но текущие данные можно экспортировать снова.
