# ST Catalog Manager — MVP 0.1.0

Локальное приложение на Python 3.12, PySide6 и SQLite для пяти каталогов ST Education & Knowledge. Интерфейс на русском языке. Сервер, учётная запись и интернет для работы не требуются. Программа не загружает файлы в Tilda автоматически.

**Состояние поставки:** исходный код и проверенное ядро обработки данных. Windows EXE в этой среде не собран. Приложен воспроизводимый Windows-сценарий сборки с тестами и проверкой запуска упакованного приложения. Локальная проверка GUI заблокирована системной песочницей macOS при инициализации Qt. Не считайте эту поставку проверенным Windows-релизом до выполнения сборки и приёмки ниже.

## Что входит

- Пять оригинальных CSV: 556 строк, 194 основных/самостоятельных позиции и 362 связанных варианта. При первом запуске они загружаются автоматически; ручной первоначальный импорт не нужен.
- Неизменяемые для приложения оригиналы в `st_catalog/data`, контрольные суммы SHA-256 и отдельно `initial-catalog.sqlite3` для просмотра/восстановления первоначального состояния.
- Дерево товаров и вариантов, поиск, фильтры сайтов и категорий.
- Карточка товара: название, цена, категория, артикул, бренд, фото, SEO и остальные колонки.
- Расписание как текст без автоматической смены часовых поясов. Добавление и копирование вариантов; постоянные 12-значные UID, отдельные External ID и Parent UID.
- HTML: исходный код и безопасный визуальный просмотр с редактированием текстовых фрагментов без пересборки разметки. Сложные опции и Tabs редактируются в расширенном режиме.
- Подтверждаемые соответствия курсов между сайтами, отдельные значения для каждого региона и атомарное массовое применение изменений/новых групп.
- Импорт одного/нескольких CSV, перетаскивание, определение сайта по имени и URL, сравнение трёх состояний, сохранённые конфликты.
- Экспорт изменений или полного каталога, предварительное «Было → Стало», проверка целостности, пять отдельных CSV, ZIP и отдельный список ручного удаления.
- SQLite, журнал, сведения об импортах/экспортах, резервное копирование, перенос и восстановление.

## Запуск разработчиком

Нужен Python 3.12+; проверенная версия интерпретатора — 3.12.14. На Windows в PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m st_catalog
```

Для разработки на macOS/Linux команды аналогичны, Python находится в `.venv/bin/python`. Для проверки на отдельной базе:

```powershell
.\.venv\Scripts\python.exe -m st_catalog --data-dir .\work\test-data
```

Основная пользовательская база Windows: `%LOCALAPPDATA%\STCatalogManager\catalog.sqlite3`. Она находится вне каталога программы. Обновление/замена папки приложения её не трогает. Файлы SQLite нельзя копировать во время работы обычным файловым копированием: используйте кнопку резервной копии. Приложение запрещает одновременное открытие одной базы вторым экземпляром.

## Получение Windows-приложения без Python у сотрудника

Сборку выполняет разработчик/администратор один раз на Windows 10/11 x64 с Python 3.12 и доступом к PyPI:

1. Распакуйте исходники.
2. Запустите `Build Windows.cmd` двойным щелчком либо `powershell -NoProfile -ExecutionPolicy Bypass -File build-windows.ps1`.
3. Сценарий создаст изолированное окружение, установит зафиксированные зависимости, выполнит тесты (включая GUI), соберёт PyInstaller-приложение и проверит его запуск на отдельной базе.
4. Результат: `dist/STCatalogManager-Windows-x64.zip`.
5. Передайте сотруднику этот ZIP. Сотрудник распаковывает его и запускает `STCatalogManager.exe` двойным щелчком. Python и терминал сотруднику не нужны. Папка `_internal` должна оставаться рядом с EXE.

Это переносимая сборка, отдельный MSI/установщик не реализован. EXE не подписан цифровой подписью. Также подготовлен GitHub Actions workflow `.github/workflows/windows.yml` (его запуск не выполнялся в этой сессии). Исходники никуда не опубликованы.

## Обновление расписания ДипИФР на пяти сайтах

1. Откройте приложение. Все пять каталогов появятся автоматически.
2. При необходимости нажмите «Загрузить CSV» или перетащите файлы. Отметьте полноту только для экспорта **всех** разделов, вариантов и полей. Для выгрузки отдельного раздела оставьте флажок выключенным.
3. Разрешите найденные конфликты. Для каждого поля доступны предыдущее, локальное и новое значения. Пока конфликт не разрешён, экспорт соответствующего сайта блокируется.
4. Найдите «Онлайн-курс ДипИФР (рус)». Подтвердите риск устаревших данных перед редактированием.
5. Нажмите «Региональные версии». На каждом сайте выберите нужный основной курс и подтвердите соответствия. Предложения сортируются по названию, URL, категории, структуре и дополнительному признаку External ID, но не объединяются автоматически.
6. Во вкладке расписания включите галочками нужные строки. Введите расписание и цену отдельно для каждого сайта. Время не конвертируется и не копируется автоматически.
7. Во вкладке «Новые группы» выберите сайты и заполните новую группу и цену. В этом же действии можно изменить поле основного курса на выбранных сайтах.
8. Посмотрите «Было → Стало» и подтвердите сохранение. Все выбранные действия применяются одной транзакцией; ошибка откатывает всю операцию.
9. Нажмите «Подготовить CSV для Tilda», выберите сайты. По умолчанию — изменения. У изменённого курса также выгружаются полные строки родителя и остальных активных вариантов, чтобы сохранить состав семейства.
10. Проверьте предупреждения, повторно подтвердите риск устаревших данных и выберите папку. Для каждого экспорта создаётся новая подпапка, прошлые файлы не перезаписываются.
11. Вручную загрузите файлы в соответствующие каталоги Tilda. Инструкция находится рядом с CSV.
12. В истории экспортов отметьте успешную загрузку конкретного файла. Затем загрузите свежую выгрузку Tilda для сравнения значений.

Одиночная правка: двойной щелчок по группе → расписание/цена → сохранить. При смене расписания название варианта обновляется только если оно точно соответствует шаблону «Название родителя - старое расписание». Пользовательские названия сохраняются.

## Данные, актуальность и история

Приложение хранит три независимых состояния: оригинальные данные, последнее известное состояние Tilda и рабочие значения. JSON внутри SQLite сохраняет строки без преобразования чисел, валют, HTML, пустых ячеек и неизвестных колонок; идентификаторы всегда строки. Родительские связи определяются внутри сайта по Tilda UID, а региональные соответствия хранятся отдельно.

При новой выгрузке непересекающиеся изменения объединяются. Если и локально, и в CSV изменено одно поле по-разному, сохраняется конфликт. Отсутствующая колонка не очищает сохранённое поле. Частичная выгрузка не удаляет отсутствующие товары. Полная выгрузка создаёт отдельный конфликт отсутствия, кроме ранее помеченных неизменённых записей для удаления: их отсутствие подтверждается полной выгрузкой. Исходная запись и история остаются в базе.

Дата в имени CSV хранится отдельно от даты загрузки. Часовой пояс даты имени неизвестен. В журнале время UTC. Программа не утверждает, что каталог актуален, потому что файл загружен сегодня. В этом MVP предупреждение о риске консервативно показывается даже после новой загрузки; согласие действует только в текущем сеансе редактирования, перед экспортом требуется снова.

Статусы имеют разный смысл:

- «Сохранено» — локальное изменение.
- «Подготовлено к экспорту» — снимок сформирован в транзакции подготовки.
- «Экспортировано» — CSV создан; файл мог ещё не попасть в Tilda.
- «Импорт подтвержден» — пользователь сообщил об успешной загрузке.
- «Проверено по Tilda» — конкретное значение совпало с загруженным CSV. Это проверка по файлу, не прямое обращение к сайту и не гарантия свежести файла.

Подготовка завершается атомарно; при ошибке файлы и записи экспорта откатываются. В истории обычно виден итоговый статус «Экспортировано». Проверка старого экспорта ограничена номером изменения, поэтому не подтверждает более позднюю правку.

## Удаление и отмена

«Удаление» создаёт пометку и инструкцию; родитель помечается вместе с вариантами. Такие строки не входят в CSV, но **исключение из файла не удаляет товар в Tilda**. Сотрудник удаляет их вручную и может отметить это в разделе «Удаление в Tilda». Только свежая полная выгрузка подтверждает отсутствие.

Новый вариант, который ещё не экспортировался, можно локально отменить. Если его уже включали в файл, программа считает, что он мог попасть в Tilda, и готовит ручное удаление. Кнопка «Отменить изменения» возвращает запись к последнему известному CSV, сохраняя журнал. Она не откатывает данные на сайте.

## Резервные копии и перенос

«Настройки» → «Сохранить резервную копию / перенести базу». Полученный SQLite-файл перенесите на другой компьютер и выберите «Восстановить из копии». Восстанавливается вся база, включая историю и соответствия.

Автоматические копии создаются при запуске, перед обновлением CSV, перед восстановлением и при закрытии. Хранятся последние 30 в пользовательской папке `backups`; копии, явно сохранённые пользователем в другое место, не очищаются. Перед восстановлением проверяются целостность SQLite, версия схемы и данные. Текущая база предварительно копируется.

## Правила Tilda и источники

Основной источник структуры — пять приложенных CSV. Официальная документация проверена 12.10.2026: https://help-ru.tilda.cc/online-store/import-export. Ссылка https://help-ru.tilda.cc/online-store-payments/import-export перенаправляет на ту же страницу.

Tilda UID нужен для обновления существующей позиции, Parent UID связывает вариант с родителем, Editions описывает свойства, Modifications — дополнительные опции. Tabs:N сопоставляются с вкладками. Не включайте игнорирование Tilda UID; иначе возможно создание дубликатов.

Возможность самостоятельно назначать UID новым строкам и необходимость ручного удаления приняты из предоставленного пользователем ответа поддержки. 12 цифр выбраны по реальным файлам; приложение проверяет уникальность. Окончательная совместимость новых UID и особенностей `::` требует пробного импорта в копию Tilda-проекта.

`docs/tilda-export-settings.jpg` — исходная справка **настроек экспорта**, а не доказательство настроек обратного импорта. Программа не выводит неизвестные переключатели Tilda как подтверждённые правила.
